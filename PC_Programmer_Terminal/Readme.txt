Folder containing the Python code for the program to be run on the personal computer (PC) to control the operation of the Arduino board, specifying the order and nature of the SPI transfers in order to write to and read from the microprocessor’s code and data areas. This program uses serial communication (9600 bps, 8 bits, one stop bit, no parity bit) to interact with and exchange information—via text strings with ASCII-encoded characters—with the Arduino board.
