Folder containing the C code, which must be compiled and uploaded to the Arduino board to operate the master SPI interface that interacts with the microprocessor. The firmware compiled from the code in this folder allows the Arduino board, on the one hand, to interact with the programmer via a serial communication interface—using the Mini-B USB connector and the CH340 bridge chip—and, on the other hand, to control the SPI communication signals with the microcontroller. The SPI communication speed, which is defined by the `SCK` signal generated by the Arduino board, is set to 191 Hz, a speed slow enough to minimize communication errors with the microprocessor and suitable for programming purposes.
